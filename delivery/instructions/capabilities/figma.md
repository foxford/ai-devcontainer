## Figma — только для этого проекта

Каталог выбирает платформенный MCP `figma`. Для доставки включи FIGMA_MCP_ENABLED в локальных секретах; затем пройди OAuth у нужного агента. Автоматический login не выполняется. Используй данные Figma как источник дизайна, соблюдая проектные компоненты и мандат на изменение интерфейса.
