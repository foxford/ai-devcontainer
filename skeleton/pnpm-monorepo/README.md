## Быстрый старт

```bash
# 1. На машине должна стоять платформа (один раз):
#    curl -fsSL https://raw.githubusercontent.com/foxford/ai-devcontainer/main/install.sh | bash
# 2. Открыть репозиторий в VS Code → Reopen in Container
# 3. Внутри контейнера всё уже стоит: нода, pnpm, AI-тулзы, скиллы
pnpm install
```

Окружение приезжает из **ai-devcontainer**: тулчейн запечён в образ `dev-base:local`,
скрипты и скиллы монтируются из клона платформы. Обновление — `ai-devcontainer update`
на хосте и Rebuild Container здесь. Подробности devcontainer'а — в
[.devcontainer/devcontainer.json](.devcontainer/devcontainer.json).

## Команды

Справочник по Nx и pnpm — в [MONOREPO.md](MONOREPO.md) (раздаётся платформой).

E2E живут отдельно от остальных таргетов: `e2e/` — не пакет монорепы, в nx-граф
не входит, и в `pnpm test` (это vitest) не попадает. Гоняются явно из корня:

```bash
pnpm run e2e              # прогон
pnpm run e2e:type-check   # tsc по спекам (playwright типы не проверяет)
pnpm run e2e:report       # html-отчёт последнего прогона
```
