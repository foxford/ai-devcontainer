# AGENTS.md

Точка входа для AI-агентов этого репозитория — Claude Code, Hermes-роли
(team-lead, tech-lead, developer, qa, documenter, security-auditor) и любых
других.

**Сначала прочитай [AGENTS.platform.md](AGENTS.platform.md)** — общий контракт
платформы: обязательное чтение, quality gates, жёсткие ограничения, Hermes-флоу,
работа со скиллами. Он раздаётся платформой и обновляется централизованно
(`adc update`), поэтому в гите проекта его нет.

Здесь — **только то, что специфично для этого проекта**. Всё, что верно для всех
проектов foxford, правится в платформе, а не тут: иначе правило разъедется по
репозиториям.
