# Obsidian

Бандл подключается capability `obsidian`. [bundle.json](bundle.json) экспортирует инструкции, скилл и определение MCP из этого каталога. Устанавливаемых тулз в нём нет: Obsidian и плагин Local REST API настраиваются на хосте.

Для MCP нужен OBSIDIAN_API_KEY: из терминала проекта выполните `adc mcp enable obsidian --project`. Секрет хранится локально и не коммитится. Файловый доступ к vault возможен только при явном подключении его репозитория к ADC; автоматического маунта личных заметок нет.
