## Chrome DevTools — только для этого проекта

Используй MCP chrome-devtools для диагностики фронтенда: профилирования, трейсов, сетевых запросов, throttling и Core Web Vitals. Для начала изучи команды запуска приложения и выбери правильный URL/порт проекта. Не включай публикацию метрик или телеметрию без поручения. Браузерный профиль изолирован. Наличие этого MCP не включает Playwright MCP и не заменяет проектные e2e; эти возможности выбираются отдельно.
