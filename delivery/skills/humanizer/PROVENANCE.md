Локальные изменения:

- Рамка ADC, имя `humanizer`, русская область применения и прямой запуск собственного Python-сканера в изолированном окружении `uv`; русский сканер не маршрутизирует нерусский текст обратно на себя. `agents/openai.yaml` использует `$humanizer`.
- Зависимости запускаются отдельно от Python-проекта и только в рамках уже разрешённой установки; отдельного установщика или Go-обвязки ADC нет. Пины `razdel==0.5.0` и `pymorphy3==2.0.6` взяты из [upstream requirements.txt](https://github.com/ilyautov/humanizer-ru/blob/8c337c3567096758433c475f1d60f2543f6bc94f/requirements.txt); собственный черновик ограничен текущей задачей, пользовательские файлы не изменяются скрыто. Общий дневник не получает предпочтения одного проекта автоматически.
- Тире сохраняется по грамматике, жанру и голосу автора. Длинное и короткое тире исключены из HARD BANS, определение через тире исключено из штрафуемой сигнатуры; пунктуация доступна в `context_markers` и статистике без штрафа и ненулевого exit только за тире.
- Жанр выбирается до измерения и сохраняется при повторном прогоне и независимой сверке. Нормы научного, технического, юридического и художественного текста имеют приоритет над совпадением и баллом. Все машинные находки требуют чтения в контексте.
- Исправлены примеры с выдуманными источниками, метриками, причинностью, изменением времени и потерей авторских деталей. Убраны квоты на вопросы, идиомы, длины и ошибки, требования дописывать голос, события или случайность. Сохранены номера и тематика всех паттернов.
- Отчёт не устанавливает машинное авторство и не требует полного рерайта по низкому баллу. `--before` показывает лишь изменения извлечённых элементов: `facts.ok` означает отсутствие обнаруженных изменений, `semantic_verified` всегда `false`. Потерянные и добавленные элементы, кванторы и количества требуют сверки и дают CLI exit 2; это не доказательство смысловой ошибки. Exit 1 означает приоритетные совпадения, exit 0 — отсутствие этих машинных сигналов; смысл при любом коде проверяется отдельно. JSON сохраняет поля upstream и добавляет `context_markers`; названия полос балла отражают объём проверки, а не обязательную правку.
- Markdown-абзацы записаны одной строкой по правилам проекта.

В ADC: `uv run --no-project --no-config --isolated --python /usr/bin/python3 --no-python-downloads --with-requirements <папка-скилла>/requirements.txt python -I -B <папка-скилла>/scripts/scan.py <файл> --genre <жанр> --json`. Исходник для сравнения передаётся через `--before <файл>`, stdin через `-`. Вне ADC укажите установленный Python 3.10+ через `--python python3` либо используйте `python3 -I -B <папка-скилла>/scripts/scan.py` в заранее подготовленном окружении с зависимостями из `requirements.txt`. Не используйте окружение проекта или скачанный upstream-пакет вместо файлов скилла. Действующее разрешение на зависимости повторного подтверждения не требует; в новой среде применяются правила её проекта.
