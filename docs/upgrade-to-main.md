# Переход на новый ADC

Ветка v0 содержит прежнюю платформу и обновлённую команду adc update. Без аргументов она остаётся на v0. Флаг --branch main запускает новый установщик со стандартными каталогами ~/.local/share/ai-devcontainer и ~/.adc. Данные агентов и проектов не перемещаются.

У установленного раньше CLI выбора ветки ещё нет. Получите исправление один раз на хосте:

```sh
git -C "$HOME/.local/share/ai-devcontainer" fetch origin v0 && git -C "$HOME/.local/share/ai-devcontainer" switch --detach FETCH_HEAD
```

Сохраните работу агентов и редактора, остановите старые devcontainer. Их данные нужны для резервного копирования; не удаляйте контейнеры и тома.

```sh
docker ps --filter label=devcontainer.local_folder --format '{{.Names}}'
docker stop <имена-контейнеров>
adc update --branch main
```

Если ADC установлен в переопределённом AI_DEVCONTAINER_HOME, используйте путь этой установки при получении v0. Незакоммиченные изменения в платформе нужно сохранить перед переходом. Новый установщик проверяет остановку контейнеров, копирует прежнюю платформу вместе с .git в ~/.adc/backups/platform-v0 и сверяет содержимое. Только затем он переключает обычный клон на main, собирает Go-команду и обновляет PATH и completion. Каталоги ~/.ai-devcontainer-dev, рабочие репозитории и старые тома этот шаг не меняет.

После установки откройте новый терминал. Создайте план миграции, резервную копию и импортируйте данные через новый adc. Порядок и ограничения описаны в [инструкции main](https://github.com/foxford/ai-devcontainer/blob/main/docs/migration.md).
