## Graphify: карта кода этого checkout

Для вопросов об архитектуре, связях модулей и последствиях изменений сначала используй MCP Graphify этого checkout: `graphify_query`, `graphify_explain`, `graphify_path`, `graphify_affected`. Если MCP недоступен, выполни `adc tools graphify index`, затем `graphify query "вопрос" --budget 1500` из корня проекта. Читай исходники найденных узлов и проверяй выводы. Для точного поиска строки или небольшого знакомого файла достаточно `rg` и чтения файла.

ADC запускает проверку и обновление локального индекса в фоне после синхронизации, подготовки worktree и перед запуском агента. Запуск Orca, агента и готовность workspace не ждут индексации. Вызовы инструментов MCP и `adc tools graphify index` проверяют и обновляют индекс с ожиданием результата. Путь индекса: `<checkout>/graphify-out/graph.json`, журнал фонового обновления: `<checkout>/.adc/graphify.log`. Каждый worktree имеет свой индекс. Полный каталог файлов читать вручную для подключения индекса не требуется. Скилл: `.claude/skills/graphify/SKILL.md`.

Индекс отражает структурные связи кода и не заменяет исходники, проверки или документацию. Отсутствие результата не доказывает отсутствие связи: продолжай через `rg` и чтение. Семантический анализ документов с моделью выполняется только по отдельному запросу, автоматически ADC его не запускает. При ошибке индекса сообщи об этом и работай с исходниками; `adc tools graphify index` повторяет построение.
