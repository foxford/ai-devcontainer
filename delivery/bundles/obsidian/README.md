# Obsidian

Бандл подключается capability `obsidian`. [bundle.json](bundle.json) экспортирует инструкции, скилл и MCP, а `activation` описывает требования и вопросы CLI. Устанавливаемых тулз в нём нет.

Для активации нужны запущенный Obsidian с открытым vault, включённый плагин Local REST API, доступный из runtime адрес `/mcp/` и API key из настроек плагина. Для предложенного HTTP-адреса включите Enable HTTP server на порту `27123`. URL `host.docker.internal` подходит только при доступности этого хоста из контейнера; localhost означает контейнер. HTTPS требует доверенного сертификата.

В терминале проекта выполните `adc project capability add obsidian`. CLI спросит адрес и недостающий ключ со скрытым вводом, сохранит адрес в `.agents/mcp.local.json`, ключ в `.agents/mcp.secrets.env`, проверит MCP и доставит конфиги агентов. Повторное добавление повторно проверяет сохранённые параметры; `adc mcp doctor obsidian --fix` позволяет их изменить. Ошибка соединения не объявляется успешной активацией. Секреты локальны и не коммитятся; запуск и sync среды не задают вопросов.

Файловый доступ к vault возможен только при явном подключении его репозитория к ADC; автоматического маунта личных заметок нет. Полный маршрут настройки и ограничения сети описаны в [справочнике](../../../docs/workspace.md#obsidian).
