## Obsidian — только для этого проекта

Каталог выбирает платформенный MCP `obsidian`. Он обращается к запущенному Obsidian на хосте по настроенному адресу `/mcp/` и требует локальный OBSIDIAN_API_KEY. Активация: `adc project capability add obsidian`; диагностика и исправление адреса/ключа: `adc mcp doctor obsidian --fix`. Область чтения и изменений vault определяется поручением пользователя; наличие сервера не разрешает переписывать заметки. Секрет не помещай в Git.
