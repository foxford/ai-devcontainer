# Карта композиции — кому отдаём фронтенд-задачу

`senior-frontend` — диспетчер. Он не переизобретает то, что уже умеют соседние
скиллы платформы, и не даёт им сорваться в самодеятельность.

Все скиллы лежат в одном плоском пространстве: платформенный слой
`/opt/ai-devcontainer/skills` плюс проектные форки в `<repo>/.agents/skills`.
Собранное дерево, которое видит агент, — `<repo>/.claude/skills/`. Полный список
с описаниями — `AGENTS.skills.md` в корне проекта.

## Гейт: мандат на дизайн

Перед любой передачей в дизайн-скилл определи уровень (подробно — в `SKILL.md`):

- **A. Встроиться** — по умолчанию. Дизайн-скилл не зовём вовсе.
- **B. Улучшить в рамках системы** — можно `impeccable` в узких командах.
- **C. Новый визуальный мир** — объявляется человеком, не выводится из того, что
  интерфейс выглядит средне.

Уровень определяется **до** открытия скилла. Открытый без рамки дизайн-скилл
считает себя вправе поменять шрифт, палитру и сетку — это его нормальное поведение,
а не сбой.

## Правила композиции

1. **Один скилл за раз.** Довёл ветку доступности — открывай ветку производительности.
   Одновременно открытые `impeccable` и `design-taste-frontend` дают противоречивые
   директивы по стеку, шрифтам и иконкам.
2. **Выход одного — вход следующего.** Замеры `chrome-devtools` становятся базовой
   линией; следующая итерация обязана её уважать, а не мерить заново на глаз.
3. **Не переизобретай чужую зону.** Спросили «какой у нас CLS» — открой браузер
   и померь, а не оценивай по коду.
4. **Ничего не ставим молча.** Любая новая зависимость из любого скилла — вопрос
   человеку. Правило платформы сильнее рекомендации скилла.
5. **Файлы-побочки объявляются заранее.** `impeccable init` / `document` / `extract`
   пишут `PRODUCT.md`, `DESIGN.md`, `.impeccable/` в репозиторий. Предупреди.

## Антипаттерны

- Открыть дизайн-скилл на задаче «добавь поле в форму» и заодно поменять шрифт.
- Принести из чужого скилла `npm install` в pnpm-репозиторий.
- Прогнать чек-лист `redesign-existing-projects` как список обязательных правок:
  он написан для сайта, который редизайнят целиком, а не для правки экрана.
- Мигрировать Tailwind v3 → v4, потому что скилл называет v4 дефолтом.
- Сдать вёрстку, ни разу не открыв браузер.
- Держать `DESIGN.md` и код в расхождении, тихо выбрав одну из версий.

## Куда эскалировать из фронтенда

- **Контракт API** → `senior-backend`, согласование с человеком.
- **Выбор фреймворка и модели рендеринга для нового аппа** → `senior-architect`,
  плюс семь вопросов из `references/forcing_questions.md`.
- **Бренд, тон, копирайт** → `brandkit` (визуал) и `humanizer` (текст).
- **Инфраструктура, CI, деплой** → вне зоны этого скилла.
