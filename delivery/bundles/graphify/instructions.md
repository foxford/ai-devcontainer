## Graphify: карта кода этого checkout

Для вопросов об архитектуре, связях модулей и последствиях изменений сначала используй MCP Graphify этого checkout: `graphify_query`, `graphify_explain`, `graphify_path`, `graphify_affected`. Если MCP недоступен, запускай `graphify query "вопрос" --budget 1500` из корня проекта. Затем читай исходники найденных узлов и проверяй выводы. Для точного поиска строки или небольшого знакомого файла достаточно `rg` и чтения файла.

ADC создаёт локальный индекс при синхронизации и проверяет изменения перед запуском агента и каждым MCP-запросом. Путь индекса: `<checkout>/graphify-out/graph.json`. Каждый worktree имеет свой индекс. Полный каталог файлов читать вручную для подключения индекса не требуется. Скилл: `.claude/skills/graphify/SKILL.md`.

Индекс отражает структурные связи кода и не заменяет исходники, проверки или документацию. Отсутствие результата не доказывает отсутствие связи: продолжай через `rg` и чтение. Семантический анализ документов с моделью выполняется только по отдельному запросу, автоматически ADC его не запускает. При ошибке индекса сообщи об этом и работай с исходниками; `adc tools graphify index` повторяет построение.
