## Changesets — только для этого проекта

Прочитай .changeset/config.json, package.json и правила релизов репозитория. Для изменений публикуемых пакетов добавь changeset с правильными именами пакетов, уровнем semver и объяснением для потребителя. Соблюдай fixed/linked группы и ignore из конфигурации; внутренние изменения без релиза не требуют фиктивного bump. Не запускай version/publish и не создавай теги без поручения. Проверь changeset штатной командой проекта (обычно pnpm changeset status).
